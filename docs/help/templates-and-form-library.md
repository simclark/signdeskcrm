# Templates and Shared library

**Templates** store reusable field layouts on top of a PDF so you do not re-place signatures every time. The **Shared library** is the shelf of forms your workspace publishes for the team to use and clone.

Open **Templates** in the left nav. Switch between **All templates** and **Shared library** as needed.

## All templates

Workspace templates you create, import, clone, or customize. Every workspace member can see these.

### Common actions

| Action | Description |
|---|---|
| **New template** | Start from a document or upload |
| **Import** | Bring in a PDF (and optional JSON field map) |
| **Prepare** | Place roles, fields, and optional data-source bindings |
| **Clone** | Copy a template so you can customize |
| **Activate / Deactivate** | Control whether the template is offered for new work |
| **Archive** | Retire a template without deleting history |
| **Add to library** | Publish to your workspace Shared library (**Admin / Owner**) |
| **Remove from library** | Unpublish (**Admin / Owner**) |

## Shared library

Templates published by an Admin or Owner for teammates to reuse.

| Badge | Meaning |
|---|---|
| **Library** | Published by your workspace for teammates to reuse |

Members can **create envelopes** from shared forms and **clone** them to customize. They cannot edit or archive the published original in place. Admins can edit published forms, or remove them from the library first.

## Prepare a template

On the prepare screen:

1. Define **signer roles** (named slots such as Client or Counterparty — rename inline). People are mapped into those slots when you create an envelope.
2. Place fields: Signature, Initials, Date, Text, Checkbox.
3. Assign fields to roles, or set fill mode to **Complete before send** (stamped on send).
4. Optionally bind complete-before-send fields to a **data source** (contact, company, Prefill record, deal terms, custom, or role) under Advanced.
5. Save.

When you create an envelope from the template, recipients map to those roles and fields appear ready to send.

## Tips

- Clone a Shared library form before changing field placement for your market or brand.
- Keep one “gold” template per packet type and archive old versions.
- Members can use and clone library forms; only admins publish or remove library entries.
- After prepare, try a test envelope to yourself before sending to clients.
