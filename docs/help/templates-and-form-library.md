# Templates and Form library

**Templates** store reusable field layouts on top of a PDF so you do not re-place signatures every time. The **Form library** is a dual shelf of SignDesk starter forms plus forms your workspace publishes for the team.

Open **Templates** in the left nav. Switch between **All templates** and **Form library** as needed.

## All templates

Workspace templates you create, import, clone, or customize.

### Common actions

| Action | Description |
|---|---|
| **New template** | Start from a document or upload |
| **Import** | Bring in a PDF (and optional JSON field map) |
| **Prepare** | Place roles, fields, and merge tokens |
| **Clone** | Copy a template (including SignDesk starters) so you can customize |
| **Activate / Deactivate** | Control whether the template is offered for new work |
| **Archive** | Retire a template without deleting history |
| **Add to library** | Publish to your workspace Form library (**Admin / Owner**) |
| **Remove from library** | Unpublish (**Admin / Owner**) |

## Form library

Two kinds of rows:

| Badge | Meaning |
|---|---|
| **SignDesk** | Platform starter provided with the product. Clone to customize — do not edit the starter in place as if it were yours alone. |
| **Library** | Published by your workspace for teammates to reuse |

New workspaces receive SignDesk starters automatically. If a starter is missing, ask an admin or your SignDesk contact; ops can refresh starters for a workspace.

## Prepare a template

On the prepare screen:

1. Define **roles** (for example Buyer, Seller, Agent) so envelopes map people into the right slots.
2. Place fields: Signature, Initials, Date, Text, Checkbox.
3. Assign fields to roles or to **Document data** (stamped on send).
4. Add **merge tokens** where shared data should fill (listing address, deal terms, and similar).
5. Save.

When you create an envelope from the template, recipients map to those roles and fields appear ready to send.

## Tips

- Clone a SignDesk starter before changing field placement for your market or brand.
- Keep one “gold” template per packet type and archive old versions.
- Members can use and clone library forms; only admins publish or remove library entries.
- After prepare, try a test envelope to yourself before sending to clients.
