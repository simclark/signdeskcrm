# Documents

**Documents** is your shared PDF library. Upload files once, then reuse them for envelopes and templates.

Open **Documents** in the left nav.

## What you can do

| Action | Description |
|---|---|
| **Upload** | Add a PDF to the workspace |
| **Preview** | Open the file to review pages |
| **Create envelope** | Start a new envelope from this PDF |
| **Create template** | Turn the PDF into a reusable field layout |
| **Rename** | Change the display name |
| **Delete** | Remove the document (you may see a warning if it is still used by templates or envelopes) |

## Tips

- Keep filenames clear (`2026-purchase-agreement.pdf`) so teammates can find them.
- Prefer creating a [Template](templates-and-form-library.md) when the same fields and roles repeat.
- Deleting a document that is in use can break related envelopes or templates — read any warning carefully.
- Uploaded documents are workspace-scoped; other workspaces cannot see them.
