# SignDesk CRM Help Center

**In-app help for every workspace:** after login, open **Help** in the left nav (or the avatar menu). URL: `/app/help`.

The same articles live in the product at `frontend/src/features/help/articles/` so tenants can read them without leaving the app. Keep those files and this folder in sync when you edit help content.
