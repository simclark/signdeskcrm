# Glossary

Terms as they appear in SignDesk for end users.

| Term | Meaning |
|---|---|
| **Workspace** | Your organization’s SignDesk account, reached at `https://your-slug.signdeskcrm.com` |
| **Subdomain / slug** | Short name chosen at signup that becomes your workspace host |
| **Owner** | Member who created the workspace; full access including Settings |
| **Admin** | Member who can manage Settings and invites |
| **Member** | Day-to-day user without Settings access |
| **Envelope** | A PDF packet with recipients and fields sent for signature |
| **Prepare** | Screen where you add recipients, place fields, and configure the packet |
| **Signer** | Recipient who must complete assigned fields |
| **CC** | Recipient who receives a copy and does not sign |
| **Sequential routing** | Signers invited one after another in order |
| **Parallel routing** | Signers invited at the same time |
| **Complete before send** | Field values you enter on Prepare; stamped onto the PDF when the envelope is sent |
| **Data source / merge token** | Optional binding so a field can pull from contact, company, Prefill record, deal, custom, or role data |
| **Document** | A PDF stored in the workspace library |
| **Template** | Reusable field layout on a document |
| **Shared library** | Shelf of workspace-published templates teammates can use and clone |
| **Certificate of Completion** | Proof PDF with consent, hashes, and completion details |
| **Audit trail** | Timeline of envelope events (sent, viewed, signed, and more) |
| **Void** | Cancel an in-flight envelope |
| **Contact** | A person in the CRM |
| **Company** | An organization linked to contacts |
| **Stage** | Contact pipeline label (Lead, Active, Under contract, Closed, Inactive) |
| **Prefill records** | Settings name for the optional listings module |
| **Listings** | Nav name for prefill records when the module is on |
| **Follow-up** | Manual outreach task for a contact |
| **Follow-up plan** | Automated email sequence triggered by envelope events |
| **ESIGN disclosure** | Electronic records and signatures notice signers must accept |
| **Adopt signature** | Draw or type the signature style used while signing |
