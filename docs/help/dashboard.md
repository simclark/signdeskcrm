# Dashboard

The **Dashboard** (`/app`) is the home screen after login. It shows envelope health at a glance so you can jump into work that needs attention.

## What you see

Typical summary cards include:

| Card | Meaning |
|---|---|
| **Awaiting others** | Sent envelopes waiting on signers |
| **Completed** | Fully signed envelopes |
| **Drafts** | Envelopes not sent yet |
| **Expiring soon** | Sent envelopes nearing their expiration date |

Below the cards you usually see **Recent envelopes** for quick open.

## Common actions

- **New envelope** / **Send for signature** — start a packet
- Click a card or recent row to open [Envelopes](envelopes.md)

Use the left nav for Documents, Templates, Contacts, and other areas when you need deeper work.
